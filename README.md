# grade-calculator
## Functional Requirements: 
   1)The program shall repeatedly prompt the user to enter a student’s name until the user enters end.
   2)The program shall read exactly 5 whole-number scores between 0 and 100 for each student.
   3)The program shall display an error message and re-prompt for the same score whenever an entered score is less than 0 or greater than 100.
   4)The program shall calculate each student’s arithmetic average to one decimal place and assign a letter grade (A: 90–100, B: 75–89.99, C: 60–74.99, F: below 60).
   5)The program shall display the total number of students entered and the overall class average after end is entered (or "No students entered" if none were recorded).
## ## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | Below 60 |
