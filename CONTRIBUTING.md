# Coding Standards

1. **Use camelCase for variables and functions:** Write `studentCount` instead of `student_count` or `sc`.
2. **Use UPPER_SNAKE_CASE for constants:** Write `const int NUM_SCORES = 5;` instead of magic numbers in loops.
3. **Indent with 4 spaces per block:** Every `if`, `for`, and `while` body must be indented by 4 spaces.
4. **Always use curly braces `{}` for control structures:** Even single-line `if` statements must use braces to prevent logic bugs.
5. **Write meaningful variable names and brief comments:** Use descriptive identifiers like `totalClassAverage` and comment major logical blocks.
